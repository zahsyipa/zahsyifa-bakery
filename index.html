Cara Hosting Gratis di GitHub Pages

Publikasikan toko Zahsyifa Bakery milikmu ke internet dalam 5 menit!

1

Buat File HTML

Simpan semua kode di halaman ini sebagai file bernama index.html di komputer Anda.

2

Buat Repository Baru di GitHub

1. Login ke akun GitHub.com.
2. Klik tombol New Repository.
3. Beri nama repository, misalnya: zahsyifa-bakery.
4. Pilih opsi Public lalu klik Create repository.

3

Upload File `index.html`

1. Di halaman repository baru Anda, klik link "uploading an existing file".
2. Drag & Drop file index.html yang telah disimpan.
3. Klik tombol hijau Commit changes.

4

Aktifkan GitHub Pages

1. Masuk ke tab Settings di bagian atas repository.
2. Di menu sebelah kiri, klik Pages.
3. Di bawah judul Build and deployment, ubah Branch dari None menjadi main (atau master).
4. Klik Save.

Selesai! Aplikasi Siap Dilihat

Tunggu sekitar 1-2 menit. Web Anda akan dapat diakses secara publik melalui link:
https://username-anda.github.io/zahsyifa-bakery/
